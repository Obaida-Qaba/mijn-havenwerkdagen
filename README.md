# Mijn Havenwerkdagen

Persoonlijke kalender en loonraming voor havenwerk in Zeebrugge.

Open de GitHub Pages URL in Chrome on Android and choose **Add to Home screen** to install it as a web app. The app caches itself for offline use. Shifts and settings are stored in the browser on each device, so changes do not sync between phone and computer.

The net amount is an estimate. Compare it with the actual payslip before relying on it.
