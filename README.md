# Mijn Havenwerkdagen

Persoonlijke kalender en loonraming voor havenwerk in Zeebrugge.

Open de GitHub Pages URL in Chrome on Android and choose **Add to Home screen** to install it as a web app. The app caches itself for offline use. Shifts and settings are stored in the browser on each device, so changes do not sync between phone and computer.

The two October 2026 payslips are recorded as verified totals: €892.50 for 3/4/12/14 October, and €1,759.68 for 10/16/17/19/21/22/23/26/27/29/30/31 October. Daily net values for these groups are allocations of the payslip total. Other pay periods use a model calibrated from those two payslips and remain estimates.
